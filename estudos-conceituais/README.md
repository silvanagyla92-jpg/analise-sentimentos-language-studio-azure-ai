# Estudos Conceituais

Conteúdos estudados conceitualmente no ecossistema Microsoft relacionados a linguagem natural, agentes e aplicações conversacionais.

Inclui Question Answering, Conversational Language Understanding (CLU), Microsoft Copilot Studio e Azure AI Bot Service.

> Estes conteúdos devem ser apresentados como estudos conceituais, não como implementações práticas realizadas neste repositório.
