# Conversational Language Understanding (CLU)

## Conceito

CLU é uma capacidade de compreensão de linguagem natural voltada à criação de modelos personalizados capazes de prever a **intenção** de uma expressão e extrair **entidades** relevantes.

## Exemplo

```text
"Quero consultar o status do meu pedido"

Intenção: consultar_pedido
Entidade: pedido
```

## Ciclo de desenvolvimento

A documentação da Microsoft descreve etapas como definição do esquema, rotulagem dos dados, treinamento, avaliação, melhoria, implantação e previsão de intenções e entidades.

A qualidade dos dados rotulados influencia diretamente o desempenho do modelo.

## Atualização de ciclo de vida

A Microsoft informa que o CLU será descontinuado no Azure Language em **31 de março de 2029** e orienta novos projetos para Microsoft Foundry.

## Escopo deste projeto

CLU foi estudado **conceitualmente** e não é apresentado como implementação prática neste repositório.
