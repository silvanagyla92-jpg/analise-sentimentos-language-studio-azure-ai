# Summarization

## Objetivo

A sumarização automática utiliza técnicas de processamento de linguagem para produzir uma representação mais curta de um texto, preservando informações relevantes.

## Abordagens

O Azure Language disponibiliza capacidades de sumarização que podem produzir resumos de documentos e extrair sentenças consideradas relevantes, conforme o recurso e o tipo de sumarização utilizado.

## Fluxo

```text
Documento extenso
      ↓
Análise linguística
      ↓
Identificação das informações relevantes
      ↓
Resumo
      ↓
Revisão humana
```

## Aplicações

- síntese de documentos extensos;
- apoio à leitura de relatórios;
- preparação de informações para análise;
- triagem de conteúdo;
- criação de resumos para grandes volumes documentais.

## Cuidados

Um resumo pode reduzir contexto ou omitir detalhes importantes. Em situações críticas, o conteúdo original deve permanecer disponível para conferência. A sumarização é uma ferramenta de apoio, não substituto automático da leitura quando precisão e contexto completo são necessários.

## Relação com o projeto

A sumarização complementa os demais recursos de NLP ao mostrar como texto pode ser transformado em uma representação mais compacta para facilitar exploração e análise.
