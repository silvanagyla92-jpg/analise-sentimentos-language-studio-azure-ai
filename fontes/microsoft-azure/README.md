## Como as fontes são utilizadas

As referências oficiais são usadas para:

1. verificar a definição técnica de cada recurso;
2. confirmar diferenças entre serviços;
3. identificar APIs e formas de integração;
4. verificar idiomas e localidades suportados;
5. registrar limitações e requisitos;
6. acompanhar mudanças de produto;
7. evitar informações desatualizadas em um projeto de portfólio.

## Ciclo de vida

A documentação da Microsoft deve ser consultada continuamente porque serviços de IA evoluem. A página de ciclo de vida informa versões, depreciações e datas de aposentadoria. Por exemplo, a Microsoft informa atualmente que CLU e Custom Question Answering serão aposentados no Azure Language em **31 de março de 2029**.

## Critério de confiabilidade

Para informações técnicas específicas, a prioridade deste projeto é:

1. documentação oficial da Microsoft;
2. referências oficiais de API/SDK;
3. materiais educacionais oficiais;
4. fontes secundárias somente quando usadas para contexto.

## Observação

Links de documentação podem mudar com a evolução da plataforma. Por isso, o README registra o endereço oficial e recomenda consultar a página atual antes de implementar uma solução.
